# Shoot Mood Board

Retro mood board for the Alton Mason x 2010s A$AP Instagram shoot (Huntsville).

Live: https://makaihurstjob-sys.github.io/shoot-moodboard/

## Add a photo
1. Open the folder for the section under `photos/` on GitHub (works from the phone too).
2. **Add file → Upload files**, drop the image, commit.
3. The file name becomes the caption, e.g. `garage-flash-crew.jpg` → "garage flash crew". A leading number like `01-` sets the order and is hidden.

The page picks it up within about a minute.
